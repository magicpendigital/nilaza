## Journal and insights

Save an insight from a conversation or reading using the save action where available. From **Home → Open Journal** or the **Journal** tab, find and revisit saved items. You can also choose **Write a note**, add text and an optional title/mood. Check the save status; if an error appears, retry before closing. Your Journal is for reflection, not for passwords, medical records, financial information, or identity documents.

## Local storage and sync

Nilaza is moving from a local-first MVP toward protected sync flows. Exact behavior depends on the build. Check **Profile → Privacy & data** before assuming an item has synced or been deleted across every device.

No system should make an absolute safety promise. Safety requires access controls, encrypted transport, backend checks, deletion workflows, and operational monitoring.
