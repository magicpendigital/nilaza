## Account and recovery

Online authentication and password-recovery flows are being tested for the production pilot. If a recovery link expires, request a new one rather than sharing a code or token with anyone else.

## In-app inbox

The **Notifications** inbox is available in the beta build. You can filter unread items, mark one or all as read, open the related content, or dismiss an item. The inbox remains the reliable fallback when push is not ready.

## Push notifications

Push notifications are optional and should use generic copy; tarot questions, chat text, journal content, birth data, and sensitive AI results do not belong on the lock screen.

You can enable or disable each reminder type from **Profile → Notifications**. If you do not grant push permission, the in-app inbox still works.
